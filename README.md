# Zypora

一款 Windows 10 桌面 Markdown 所见即所得(WYSIWYG)编辑器,基于 **.NET 8 + WPF**,使用 **Markdig** 解析、**QuestPDF** 导出 PDF。

## 运行

```powershell
dotnet run --project E:\MyProgram\Zypora
```

或直接运行已构建的程序:

```
E:\MyProgram\Zypora\bin\Debug\net8.0-windows\Zypora.exe
```

发布自包含单文件版本(可选):

```powershell
dotnet publish E:\MyProgram\Zypora\Zypora.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

## 测试

仓库自带断言测试(无第三方框架):

```powershell
dotnet run --project tests\Zypora.Tests\Zypora.Tests.csproj
```

覆盖:查找/替换、表格解析与模板、图片解析/路径/写盘、撤销分组、行内/行级命令、光标映射、渲染与**文本恒等 fuzz**、PDF 导出、版本与命令行参数。

## 界面说明

- 顶部工具栏:最左 **≡ 文件菜单**(新建窗口 / 打开 / 保存 / 导出 PDF),旁边 **清空** 按钮,接着 **格式 ▾ 下拉菜单**(标题/加粗/斜体/列表/引用/代码/代码块/表格)与**预览 / 原生**切换,右侧是**夜间模式**与**置顶**开关。
- 工具栏右侧 **置顶**(图钉图标)开关:让窗口总在最前,置顶时图标变蓝(仅当前窗口;新建窗口默认不置顶)。
- 工具栏右侧 **夜间模式**(灯泡图标)开关:切换深灰黑底白字;状态持久化到 `%APPDATA%\Zypora\settings.json`。
- 中央编辑区:单个编辑区,两种视图模式均**可直接编辑**。
- **启动默认进入预览模式。**
- 视图模式为两态切换(工具栏按钮 或 `Ctrl+/`):**预览 ↔ 原生**;按钮文字显示下一个模式。
  - **预览**:隐藏标题 `#`、加粗 `**`、引用 `>`、行内代码 `` ` `` 等标记,分割线用横线绘制;无序列表显示为实心小黑圆点,有序列表保留序号;表格显示为带边框的网格。
  - **原生**:以等宽字体原样显示 Markdown 源码,不解析、不加样式,便于直接改源码;此模式下回车不做列表自动延续。
- **自动适应宽度**:过宽的表格会按窗口宽度自动缩放,单元格内文字自动换行,不会超出窗口被裁掉;长文本、长链接按字符自动换行。

## 支持的语法

| 语法 | 示例 |
| --- | --- |
| 标题(1~6 级) | `# 标题` |
| 加粗 | `**文字**` 或 `__文字__` |
| 斜体 | `*文字*` 或 `_文字_` |
| 行内代码 | `` `代码` `` |
| 无序列表 | `- 项目` / `* 项目` / `+ 项目` |
| 有序列表 | `1. 项目` |
| 引用 | `> 引用内容` |
| 代码块 | 三个反引号围栏 |
| 表格 | `\| A \| B \|` + `\|---\|---\|`(支持 `:--` / `:-:` / `--:` 对齐) |
| 水平分割线 | `---` |

## 撤销分组

- **连续输入合并为一步**:连续打字/删除会被合并;停顿约 800ms、输入空格或回车、或执行格式命令时断开。
- **每个格式命令自成一步**(加粗、标题、列表、代码块、替换等)。
- 撤销前若有未提交的输入,会先提交当前状态,保证重做可用。

## 查找与替换

- `Ctrl+F` 查找,`Ctrl+H` 替换,`Esc` 关闭;支持 **Aa**(区分大小写)、**全词**、**.***(正则)。
- 全部命中浅黄高亮,当前命中橙色;回车 = 下一个;支持 替换当前 / 全部替换(替换可整体撤销)。
- 查找基于源码文本偏移,重渲染后高亮自动重放。

## 表格

- 预览下渲染为带边框的 WPF 网格,支持列对齐、表头加粗。
- 工具栏 **表格** 按钮 / `Ctrl+Shift+T`:插入 3 列 2 行模板,光标选中第一个表头单元格。
- 实现要点:WPF `Table` 的文本序列化用 `\t`/`\r\n` 分隔,无法逐字保留源码,故改用「隐藏文本 + `InlineUIContainer`」方案(容器在 `TextRange` 中恰占 1 个空格,把源码行按最后一个空格拆成隐藏前段 + 容器 + 隐藏后段),从而在渲染表格外观的同时保持文档文本与源码**逐字一致**(光标映射与保存不受影响)。
- 表格在预览下不可逐格编辑,请在原生模式修改;无空格紧凑表格回退为普通文本显示。

## 图片

- **粘贴**(`Ctrl+V`)/ **拖拽**图片文件:自动把副本存到**软件安装目录的 `assets\`**,并插入 `![image N](绝对路径)`(文件名带随机值防冲突)。
- 预览中显示图片;文件缺失 / 网络地址显示占位框;未保存文档会先提示保存。
- 恒等实现:图片行沿用「隐藏 Run + `InlineUIContainer`(占 1 空格)」技巧,要求该行**含空格**(插入时生成的 `image N` alt 保证有空格);无空格的手写语法回退为文本。
- 解析顺序:绝对路径 → 文档目录 → 安装目录 → 安装目录 `assets/` 按文件名。

## 文件操作

- **新建**(`Ctrl+N`):打开一个新的空白窗口,便于同时编辑多个文件;每个窗口相互独立。
- **清空**(`Ctrl+Shift+N`):把当前窗口的文档重置为空白(不改变窗口数)。
- **打开**:在当前窗口打开 `.md` 文件。
- 打开/保存格式为 `.md`(UTF-8 文本)。
- 保存时仅写入 Markdown 源码,标记符号不会丢失或被替换(文档内容与编辑区完全一致)。
- 支持文末空行的保留。
- **未保存提示**:标题前的 `*` 表示有未保存改动;关闭窗口 / 新建 / 清空 / 打开文件前会询问「保存 / 不保存 / 取消」。

## 导出 PDF

点击 **文件 → 导出 PDF**,选择保存位置后生成 A4 版式 PDF,包含标题、正文、列表、引用、代码块等样式。

## 自动更新

启动时**后台检查**新版本;检查失败(超时/连不上/数据异常)**静默跳过**,不影响使用。

- 发现新版本 → 提示「立即更新 / 以后再说」;选择后不再提示该版本
- 立即更新 = 下载 → SHA-256 校验(可选) → 解压 → 自我替换(`Zypora.exe` → `Zypora.exe.bak` 备份)→ 重启
- 更新信息来自 `update.json`(主源在 `UpdateConfig.cs` 的 `PrimaryUpdateUrl`,留空则回退 jsDelivr / GitHub raw)
- 参数 `--no-update-check` 可跳过检查;详细设计与发布流程见 `docs/superpowers/specs/2026-10-10-zypora-update-design.md`

## 已知限制

- 数学公式、链接跳转、代码语法高亮、任务列表尚未实现。
- 代码块以等宽字体显示,不做关键字高亮。
- 撤销按"连续输入合并为一步、格式命令各一步"分组,非严格逐字符。
- 表格在预览下不可逐格编辑(需切到原生模式)。
- 图片副本存于软件安装目录 `assets\`(换电脑可能找不到图);图片不参与 PDF 导出。
- 中文输入法输入已做保护(合成期间不重渲染),但个别第三方输入法边界情况可能仍有异常。
- 为保证预览模式下也能编辑,预览中标记字符被保留、多数以透明方式隐藏(仍占极小宽度)。列表标记以实心圆点呈现,分割线通过段落下边框绘制。这是"可编辑预览"与"纯渲染"之间的取舍。
