# Zypora

一款 Windows 10 桌面 Markdown 所见即所得(WYSIWYG)编辑器,基于 **.NET 8 + WPF**,使用 **Markdig** 解析、**QuestPDF** 导出 PDF。

## 运行

```powershell
dotnet run --project E:\MyProgram\Zypora
```

或直接运行已构建的程序:

```
E:\MyProgram\Zypora\bin\Debug\net8.0-windows\Zypora.exe
```

发布单文件版本(可选):

```powershell
dotnet publish E:\MyProgram\Zypora\Zypora.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

## 界面说明

- 顶部工具栏:文件操作、视图模式切换与格式快捷按钮。
- 中央编辑区:单个编辑区,两种视图模式均**可直接编辑**。
- **启动默认进入预览模式。**
- 视图模式为两态切换(工具栏按钮 或 `Ctrl+/`):**预览 ↔ 原生**;按钮文字显示下一个模式。
  - **预览**:隐藏标题 `#`、加粗 `**`、引用 `>`、行内代码 `` ` `` 等标记,分割线用横线绘制;无序列表显示为实心小黑圆点,有序列表保留序号。
  - **原生**:以等宽字体原样显示 Markdown 源码,不解析、不加样式,便于直接改源码;此模式下回车不做列表自动延续。

## 支持的语法

| 语法 | 示例 |
| --- | --- |
| 标题(1~6 级) | `# 标题` |
| 加粗 | `**文字**` 或 `__文字__` |
| 斜体 | `*文字*` 或 `_文字_` |
| 行内代码 | `` `代码` `` |
| 无序列表 | `- 项目` / `* 项目` / `+ 项目` |
| 有序列表 | `1. 项目` |
| 引用 | `> 引用内容` |
| 代码块 | 三个反引号围栏 |
| 水平分割线 | `---` |

## 快捷键

| 快捷键 | 功能 | 备注 |
| --- | --- | --- |
| `Ctrl+B` | 加粗 | **需先选中文字**;选中后按下应用,再次按下取消 |
| `Ctrl+I` | 斜体 | **需先选中文字**;选中后按下应用,再次按下取消 |
| `Ctrl+K` | 行内代码 | 可先选中文字;选中多行时生成代码块;无选中则成对插入 |
| `Ctrl+Shift+K` | 代码块 | 当前行/选区包裹围栏;已在代码块内再按一次取消 |
| `Ctrl+/` | 切换视图 | 预览 ↔ 原生,启动默认预览 |
| `Ctrl+1` | 一级标题 | 当前行;再按一次取消 |
| `Ctrl+2` | 二级标题 | 当前行;再按一次取消 |
| `Ctrl+Shift+7` | 无序列表 | 当前行开关(可多行选中批量处理) |
| `Ctrl+Shift+O` | 引用 | 当前行开关(可多行选中批量处理) |
| `Ctrl+Z` | 撤销 | |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 | |
| `Ctrl+N` | 新建窗口 | 开一个新的空白窗口,可同时编辑多个文件 |
| `Ctrl+Shift+N` | 清空 | 清空当前文档 |
| `Ctrl+O` | 打开 | |
| `Ctrl+S` | 保存 | 首次会弹出保存对话框 |

> **加粗 / 斜体**必须在**选中文字**后才生效(未选中时按下不做任何事),再次按下取消。**行内代码**在选中多行时会自动改为**围栏代码块**;无选中时在光标处插入成对标记。引用 / 列表 / 有序列表对多行选区会整段应用。

## 列表回车行为

- 在**非空**列表项末尾按 `Enter`:自动延续同级列表标记(无序沿用符号,有序序号自动 **+1**)。
- 在**空**列表项(只有标记)按 `Enter`:取消该列表标记,变回普通空行。
- 在列表项中间按 `Enter`:光标后的内容成为新的一项并带相同标记。

## 工具栏

- **新建 / 清空 / 打开 / 保存 / 导出 PDF**
- **预览 / 原生**:两态切换视图模式(按钮文字显示下一个模式)
- **H1 / H2**:当前行切换一/二级标题
- **B / i**:加粗 / 斜体(需选中文字)
- **• 列表 / 1. 列表 / 引用 / 代码 / 代码块**:当前行或选中内容应用对应格式

## 文件操作

- **新建**(`Ctrl+N`):打开一个新的空白窗口,便于同时编辑多个文件;每个窗口相互独立。
- **清空**(`Ctrl+Shift+N`):把当前窗口的文档重置为空白(不改变窗口数)。
- **打开**:在当前窗口打开 `.md` 文件。
- 打开/保存格式为 `.md`(UTF-8 文本)。
- 保存时仅写入 Markdown 源码,标记符号不会丢失或被替换(文档内容与编辑区完全一致)。
- 支持文末空行的保留。

## 导出 PDF

点击工具栏 **导出 PDF**,选择保存位置后生成 A4 版式 PDF,包含标题、正文、列表、引用、代码块等样式。

## 已知限制

- 表格、图片、数学公式、链接跳转、代码语法高亮尚未实现。
- 代码块以等宽字体显示,不做关键字高亮。
- 撤销以"停顿快照"为粒度(自动渲染触发点),不是逐字符撤销。
- 中文输入法输入已做保护(合成期间不重渲染),但个别第三方输入法边界情况可能仍有异常。
- 为保证预览模式下也能编辑,预览中标记字符被保留、多数以透明方式隐藏(仍占极小宽度)。列表标记(`- `/`1. `)以强调色可见显示(而非 • 圆点),分割线通过段落下边框绘制。这是"可编辑预览"与"纯渲染"之间的取舍。
